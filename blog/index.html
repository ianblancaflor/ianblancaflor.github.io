Feels like I'm on the cusp of posting about this website publically for everyone to see, figured out so much today it was unreal. Locked in on the first background, a surface weather analysis map of Hurricane Dot I found off of Wikipedia.

We're on the precipice of yet another tropical storm-turned-hurricane this season and in my research I was fascinated by this map in particular. I also pulled a lot of the hex codes and color scheming from this map so I could stop using the default "lightblue" and "antiqewhite" and so on so forth.

Another major obstacle of todays session was utilizing a new marquee, which set me off an hour long detour due to the mobile responsiveness getting cooked on the live shows page. it obviously came down to the marquee element and once i removed that it was all good, and at this point i gave up and resorted to using the HTML marquee tag lol.
